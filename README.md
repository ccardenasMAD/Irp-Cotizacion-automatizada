Project Description

This repository contains the development of the corporate website for IRP (Inversiones RP). The project is structured as a modern One Page Application (SPA) designed to present the company in a clear, professional, and structured manner.

The main objective of the website is to strengthen IRP’s digital presence while providing potential clients with an intuitive and streamlined way to learn about the company, its experience, and the services it offers.

In addition to the informational sections, the platform integrates an interactive quotation system that allows users to:

Select the product or service they wish to request.

Provide their contact information.

Upload technical documentation or architectural plans required for evaluation.

This functionality enhances the commercial workflow by enabling structured data collection from the first point of contact, improving response efficiency and supporting lead management processes.

The application follows a modular component-based architecture, prioritizing reusability, scalability, and maintainability, while ensuring a clean and user-focused interface.
