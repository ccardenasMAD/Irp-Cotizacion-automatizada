Project Description

This repository contains the development of the corporate website for IRP (Inversiones RP). The project is structured as a modern single-page application (SPA) designed to present the company in a clear, professional, and structured manner.

The website's main objective is to strengthen IRP's digital presence, offering potential clients an intuitive and efficient way to learn about the company, its experience, and the services it offers.

In addition to informational sections, the platform integrates an interactive quoting system (chatbot) that allows users to:

Select the product or service they wish to request.

Provide their contact information.

Upload the technical documentation or architectural plans necessary for evaluation.

This functionality optimizes the sales workflow by enabling the structured collection of data from the first contact, improving response efficiency and supporting lead management processes.

The application follows a modular, component-based architecture, prioritizing reuse, scalability, and maintainability, while ensuring a clean, user-centric interface.
